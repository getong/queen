# Code of Conduct

Queen MQ follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).
It applies everywhere the project meets people: issues, pull requests, discussions, chats, and events
where someone speaks for the project.

## Reporting

Report a violation privately to the maintainers at conduct@queenmq.com. Say what happened, where and when, and who was involved. The report is
read only by the maintainers who handle it, and you get an answer before any action is taken.
